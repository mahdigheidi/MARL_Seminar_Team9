# Phase 2 — Slide Design

Rule:
Slides support the talk.
Slides do NOT replace the talk.

For each slide:

- Maximum 3–5 bullets
- Large figures
- Minimal text
- No paragraph blocks

Avoid:
- Copy-paste from book
- Screenshots of equations
- Dense mathematical derivations

Instead:
- Redraw figures
- Simplify diagrams
- Animate explanations

---

# Phase 3 — Speaker Notes

For every slide create:

- Main message
- 30–90 second script
- Transition sentence
- Potential audience question

The presentation should be deliverable from speaker notes alone.

# Phase 5 — Discussion Preparation

Prepare:

- 5 technical questions
- 3 critical-thinking questions
- 2 future-research questions

Goal:
Guide discussion rather than waiting for questions.

Example:

"Parameter sharing works well for homogeneous agents. What limitations would arise if agents had specialized roles?"

---

# Presentation Principles

1. Motivation before details
2. Intuition before mathematics
3. Mathematics before implementation
4. Explain every equation verbally
5. One idea per slide
6. Maintain eye contact
7. Do not read slides
8. Use transitions between speakers
9. Always connect concepts back to MARL challenges
10. Finish with a big-picture conclusion
